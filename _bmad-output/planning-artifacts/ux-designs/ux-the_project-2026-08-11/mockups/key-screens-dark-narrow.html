Dark mode required no palette re-tuning — with no shadows, gradients, or tints to translate, it is inversion. Borders go white, the two signal colours stay exactly as they are, and only electric shifts to #5C7CFF, because #0F2BFF on near-black is 2.5:1 and unreadable. A signal that changes hue by theme is a signal the owner has to learn twice.

Below 640px, the system gets more edge-to-edge, not less. Rows become stacked blocks running to the viewport edge with zero inline margin — which only looks intentional because nothing has a radius. And no column is dropped: hiding the last-confirmed time to save space would break the truth contract, so it reflows to a second line instead.
